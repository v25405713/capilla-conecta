# 🌄 Capilla Conecta

Plataforma comunitaria interactiva, chat en vivo, tablón de anuncios vecinales, comercios locales y servicios para los habitantes y visitantes de **Capilla del Monte, Córdoba**.

---

## 🚀 Despliegue en GitHub Pages

Este proyecto ya incluye el flujo automatizado de **GitHub Actions** en `.github/workflows/deploy.yml`.

### Pasos para activar en GitHub:
1. Sube este repositorio a GitHub.
2. En GitHub, ve a **Settings** (Configuración) > **Pages**.
3. En **Build and deployment** > **Source**, selecciona **GitHub Actions**.
4. ¡Listo! Tu página se compilará y se publicará automáticamente en:
   `https://<tu-usuario>.github.io/<nombre-del-repo>/`

---

## 📱 Instalación en el Celular (PWA)

No necesitas instalar archivos `.apk` inseguros o que den error de paquete:
1. Abre el enlace de la aplicación desde Google Chrome en tu celular Android (o Safari en iPhone).
2. Toca el botón **"Instalar App"** que aparece en la pantalla, o abre el menú de Chrome (los 3 puntos arriba a la derecha) y selecciona **"Instalar aplicación"** o **"Agregar a la pantalla principal"**.
3. La aplicación se instalará como una App nativa con icono oficial, pantalla completa y acceso directo sin errores de paquete.
